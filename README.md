## Проект 4. Анализ данных об оптовых продажах аудиотехники

**Цель:** Проанализировать продажи музыкальных товаров и сделать выводы.

**Стек:** Python, Pandas, Jupyter Notebook.

## Описание проекта

Вам предстоит поработать аналитиком данных в компании «Карпов Саунд», которая занимается оптовой продажей аудиотехники и предлагает широкий ассортимент товаров от ведущих мировых брендов.

«Карпов Саунд» сотрудничает с крупными розничными сетями и специализированными магазинами аудиотехники в России. Клиенты компании регулярно оставляют заявки на закупку товаров в CRM системе, менеджеры связываются с клиентами, обсуждают детали, после чего заказы либо подтверждаются менеджерами, либо по разным причинам отменяются.

В «Карпов Саунд» трепетно относятся к хранению информации о своих товарах, клиентах и заказах, однако в самый неподходящий момент хранилище данных компании оказалось временно недоступно из-за плановых работ по его оптимизации. Поэтому в рамках этого проекта все данные будут представлены не в самом удобном для анализа виде — в формате резервной выгрузки, разложенной по разным папкам на сервере компании.

Вам необходимо собрать данные из разрозненных источников, проанализировать их и сделать выводы, которые помогут руководству компании принять верные тактические решения.


## Реализация проекта
- Работа выполнена на Python с использованием Jupyter Notebook.
- Задача 1. Собрала датасет с заказами по папкам
- Задача 2. Посмотрела на общую динамику заказов, определила дни, которые выбиваются из общей картины, и построила график. Нашла причину резкого увеличения кол-ва заказов в один из дней (тест гипотезы)
- Задача 3. Посчитала ключевые метрики, посмотрела на их динамику и составила отчет
- Задача 4. Проанализировала интерес клиентов к брендам
- Задача 5. Составила отчет по продажам менеджеров

## Результат
В этом проекте проанализировала продажи музыкальных товаров:
- собрала данные,
- посчитала ключевые метрики в динамике;
- определила дни, которые выбиваются из общей картины, и выяснила причину этого;
- нашла наиболее прибыльные бренды и те, которые зря занимают место на виртуальной «полке».
