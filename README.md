## Реализация проекта
- Работа выполнена на Python с использованием Jupyter Notebook.

- 
- Подготовила данные, провела EDA и анализ платящей аудитории.
- Провела когортный анализ и написала функцию расчета retention.
- Для A/B-теста проанализировала контрольную и тестовую группы объемом более 200 000
наблюдений каждая.
- Проанализировала структуру выручки и определила продуктовые метрики эксперимента: CR
в покупку, ARPU и ARPPU.
- Для CR применила критерий хи-квадрат Пирсона, для ARPU и ARPPU - t-тест Уэлча.

## Результат
Рекомендовала не раскатывать тестовый набор предложений на всю аудиторию, поскольку это приведет к статистическому снижению конверсии в покупку и не даст статистически подтвержденного прироста ни в среднем чеке платящего пользователя, ни в общей выручке компании.
